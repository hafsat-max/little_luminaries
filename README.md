## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Teacher portal backend

The teacher portal is available at [http://localhost:3000/assigments](http://localhost:3000/assigments).

Copy `.env.example` to `.env.local` and set `TEACHER_EMAIL`, `TEACHER_PASSWORD`, and a long random `SESSION_SECRET`. For local development only, the fallback login is `teacher@littleluminaries.com` / `littleluminaries-demo`.

Assignments and uploaded files are written to the ignored `storage/` directory. Parent addresses are configured in `data/students.json`. Add `RESEND_API_KEY` and a verified `EMAIL_FROM` address to enable real parent-email delivery; without them, the same authenticated upload and persistence flow runs in development delivery mode without transmitting email.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
